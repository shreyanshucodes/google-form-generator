# Roadmap

## Next

- Add fixtures for grids, checkbox questions, and linear scales.
- Add profile packs that users can enable explicitly by survey domain.
- Produce a compact HTML summary alongside CSV and JSON exports.

## Later

- Add a browser-assisted review mode for forms that need interactive sign-in.
- Add distribution controls for users who need a specific sample mix.
- Add a small local web interface for inspecting generated datasets.

## Principle

Every improvement should make synthetic data more useful, the form mapping more
transparent, or the local workflow easier to verify.
